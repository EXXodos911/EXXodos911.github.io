This is an example post to show how the new workflow feels.

You write plain Markdown in `src/content/blog/`, push to `main`, and GitHub Actions compiles it to static HTML. No CMS, no database, no client-side rendering.

## What you get for free

- Static HTML per post, fast by default
- RSS at `/rss.xml` and sitemap for search
- Clean reading view with the same black minimal theme

Delete this file when you are ready, or keep it as your first real post.
